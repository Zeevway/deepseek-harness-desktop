DeepSeek Harness 是什么

它是 DeepSeek AI 官方开源的智能体框架，可在授权范围内理解代码和文件、调用工具，并完成多步骤任务。本桌面版封装官方核心，额外提供安装、更新与本机设置界面。

文件范围与存储

工作区与 Harness 数据

工作区是你的项目目录；Harness 数据包含配置、日志和会话。两者不会因为程序安装在 D 盘而自动迁移。

程序默认 D:\DeepSeek Harness Desktop应用文件和卸载程序
Harness 数据默认 Windows AppData配置、日志、会话和插件
工作区尚未选择你允许 Harness 处理的项目

建议为每个项目选择独立文件夹，不要直接选择磁盘根目录、Windows 目录或整个用户目录。

默认位于当前 Windows 账户的 AppData。更改位置不会移动你的工作区；迁移成功前不会删除原数据。

工作区和权限是两层控制

工作区定义当前项目；下一步的权限决定工具能否写入或访问工作区以外的位置。遇到审批提示时，请先核对路径和命令。
